# App Resources

Put app resources here before adding them to the Xcode target.

- `Assets.xcassets`: App icon, colors, and visual assets.
- `GoogleService-Info.plist`: Real Firebase config. Do not commit this file.
- Localized strings files if the app supports more than English.
